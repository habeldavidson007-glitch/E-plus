# Experiment Tasks

This directory contains all tasks for the E+ cognitive load experiment.

## Task Files

### Experimental Tasks (Python + E+ pairs)
- `task1_conditional.py` / `task1_eplus.eplus` - Conditional complexity
- `task2_nested.py` / `task2_eplus.eplus` - Nested reasoning  
- `task3_state.py` / `task3_eplus.eplus` - State + loop management
- `task4_data.py` / `task4_eplus.eplus` - Data transformation (hostile task)

### Test Files (validator demos)
- `test_validation.eplus` - Validator stress test
- `test_all_features.eplus` - Feature demonstration
- `test_ram.eplus` - RAM monitor example

## Usage

Participants receive either the Python or E+ version depending on experimental condition. See EXPERIMENT_PROTOCOL.md for administration details.
